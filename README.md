# Road to War: a virtual tour

An interactive tour of three scenes from the run-up to the Second Anglo-Boer War:
gold at Langlaagte, the influx of Uitlanders into Johannesburg, and the Jameson Raid at Doornkop.

## Publish it on GitHub Pages
1. On github.com, create a new public repository (for example `road-to-war-tour`).
2. Click **Add file > Upload files**, drop in `index.html`, and commit.
3. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute or two the tour is live at `https://YOUR-USERNAME.github.io/road-to-war-tour/`.

## Notes
- The scenes are illustrations drawn in code, not photographs. Real Street View can only show these places as they look today, so each stop has a button that opens it.
- To use archive photos or your own artwork later, replace the scene functions (`s1`, `s2`, `s3`) in `index.html` with `<image>` tags.
